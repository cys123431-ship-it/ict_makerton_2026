# 모여스터디 디자인 가이드 (v2)

이 문서는 모여스터디 모바일 앱의 **로그인 · 메인(홈) · 목록 · 모임 상세** 화면에 적용된 공통 디자인 규칙입니다.
v1 가이드를 바탕으로, 화면을 확장하며 바뀐 스타일(메인 컬러 블루, 검색창, 버튼 너비 등)을 반영했습니다.
기존 정보의 내용과 순서는 유지하고, 새 화면도 아래 규칙을 따릅니다.

> **v1 → v2 주요 변경**
> - 주요 강조색: `#6C4DFF`(보라) → `#2563EB`(블루)
> - 목록 카드 버튼 너비: `Hug contents` → `Fill container`
> - 목록 화면에 검색창 추가 (제목과 필터 사이)
> - 보조 색상(연한 배경, 진행 바, 아바타)과 화면별 규칙 추가

## 2. 글자 (Noto Sans KR)

| 용도 | 크기 / 굵기 |
|---|---|
| 화면 제목 (모여스터디, 내 모임) | `24px / Bold` |
| 상세 화면 모임 제목 | `24px / Bold` |
| 카드 제목, 섹션 제목 | `18px / Bold` |
| 상단 내비게이션 제목 | `16px / Medium` |
| 본문, 입력 문구 | `14px / Regular` |
| 일정·장소 등 보조 정보 | `13px / Regular` |
| 모집 인원 | `13px / Medium` (강조색) |
| 버튼 문구 | `14px / Medium` |
| 필터 칩 | `14px / Medium` |
| 과목 태그 | `12px / Medium` |
| 탭바 라벨 | `11px / Regular` (선택 시 Medium + 강조색) |

- Noto Sans KR에는 Semibold가 없어 **Medium**으로 대체합니다.
- 긴 카드 제목은 **최대 두 줄**까지 표시하고, 넘치면 말줄임(…) 처리합니다. 제목이 길어지면 텍스트와 카드 높이가 함께 늘어납니다.
- 일정·장소·모집 인원의 라벨 폭은 **51px**로 맞춰 값이 세로로 정렬되게 합니다.

## 3. 간격

| 항목 | 값 |
|---|---|
| 화면 좌우 여백 | `20px` |
| 화면 위쪽 여백 | `24px` |
| 제목 ↔ 검색창 ↔ 필터 ↔ 목록 | `20px` |
| 필터 사이 간격 | `8px` |
| 카드 내부 여백 | `20px` |
| 카드 사이 간격 | `16px` |
| 카드 내부 요소 사이 | `8px` |
| 카드 정보 ↔ 버튼 | `16px` |
| 버튼 안쪽 여백 | 위아래 `12px` · 좌우 `16px` |
| 입력창·검색창 안쪽 여백 | 위아래 `13~14px` · 좌우 `16px` |
| 상단 내비게이션 | 위아래 `16px` · 좌우 `20px` |

## 4. 모서리와 테두리

| 요소 | 모서리 | 테두리 |
|---|---|---|
| 카드 | `16px` | `1px solid #E4E2EA` |
| 버튼 | `10px` | 없음 (보조 버튼은 `1px #E4E2EA`) |
| 입력창·검색창 | `10px` | `1px solid #E4E2EA` |
| 필터 칩 | `20px` | 비선택 시 `1px #E4E2EA` |
| 과목 태그 | `4px` | 없음 |
| 진행 바 | 완전 둥글게 (높이 `6px`) | 없음 |

- 그림자 효과는 사용하지 않습니다.

## 5. 공통 컴포넌트

### 버튼
- 기본 버튼: 강조색 `#2563EB` 배경, 흰 글자, 모서리 10, 너비 **Fill container**
- 보조 버튼: 흰 배경, `#E4E2EA` 테두리, 기본 글자색
- 문구가 잘리거나 줄바꿈되지 않아야 합니다.

### 필터 칩
- 순서: **전체 · 영어 · 수학 · 코딩**
- 선택: 강조색 배경 + 흰 글자
- 비선택: 흰 배경 + 기본 글자색 + 구분선 테두리

### 검색창
- 돋보기 아이콘(18px, 벡터) + "모임 이름, 과목으로 검색"
- 흰 배경, 구분선 테두리, 모서리 10, 너비 Fill container

### 하단 탭바
- 순서: 홈 · 스터디 목록 · 내 모임 · 마이
- 흰 배경, 위쪽 구분선 1px, 아래 여백 24px
- 선택된 탭: 아이콘·라벨 강조색 / 나머지: 아이콘 `#E4E2EA`, 라벨 보조 글자색

## 6. 화면별 규칙

### ① 로그인
1. 로고(64×64, 강조색, 모서리 20) → "모여스터디"(24 Bold) → 소개 문구(14, 보조색)
2. 학교 이메일 · 비밀번호 입력창 (라벨 13 Medium)
3. 로그인 버튼 (기본 버튼, Fill)
4. 회원가입 · 비밀번호 찾기 링크 (13, 보조색)
5. "SNS로 시작하기" 구분선 아래 SNS 버튼
   - **세로 배치**, 버튼 간격 8px, 너비 Fill container
   - 문구: "카카오로 시작하기 / 네이버로 시작하기 / Google로 시작하기"
   - 왼쪽 20×20 아이콘 자리 → **각 사 공식 로고 에셋으로 교체**

### ② 메인 / 홈
1. 제목 "모여스터디" + 알림(벨) 아이콘
2. 인사 문구 (18 Bold) + 보조 설명 (13)
3. 검색창
4. **과목별 둘러보기**: 타일 4개, 순서 **전체 → 영어 → 수학 → 코딩**, 모서리 16
5. **이번 주 추천 모임**
   - 타이틀은 좌우 여백 20 유지
   - 카드 영역만 **화면 전체 너비(390px)** 가로 스크롤, 첫 카드는 왼쪽 20에서 시작
   - 카드 폭 280px, 카드 간격 12px, 아래 페이지 표시 점(활성 16×6 강조색)
6. **광고 배너**: `#17151D` 배경, 모서리 16, AD 배지 + 제목(15 Bold, 흰색) + 설명 + 64×64 이미지 자리
7. 하단 탭바 (홈 선택)

### ③ 목록
1. 제목 "모여스터디" (24 Bold)
2. 검색창
3. 과목 필터 (전체 선택)
4. 스터디 카드 목록 (Vertical, 간격 16, Fill / Hug)

**카드 정보 순서 (변경 금지)**
1. 과목 태그 (`#F7F7FA` 배경, 12 Medium)
2. 모임 제목 (18 Bold, 최대 두 줄)
3. 일정 (13)
4. 장소 (13)
5. 모집 인원 (13 Medium, 강조색, 예: `4 / 6명`)
6. `모임 자세히 보기` 버튼 (Fill container)

### ④ 모임 상세
1. 상단 내비게이션: 뒤로가기(벡터) · "모임 상세" · 공유
2. 요약: 과목 태그(`#EAF1FF` 배경, 강조색 글자) → 모임 제목(24 Bold) → 모임장(아바타 24 + 13 보조색)
3. 정보 카드: 일정 · 장소 · 기간 → 모집 인원 + 진행 바(트랙 `#E6ECF5`, 채움 강조색)
4. 모임 소개 카드: 섹션 제목(18 Bold) + 본문(14, 줄간격 160%)
5. 참여 멤버 카드: 아바타 40px, 빈자리는 점선 원
6. 하단 CTA: 찜(♡, 보조 버튼) + "참여 신청하기"(기본 버튼, Fill)

## 7. Auto Layout

### 화면과 목록
- 화면: `Vertical`, 너비 390 고정
- 목록: `Vertical`, 카드 사이 간격 16, 너비 `Fill container`, 높이 `Hug contents`
- 메인 화면의 전체 너비 영역(추천 모임 카드)은 Body 좌우 여백을 0으로 두고, 나머지 영역에 각각 좌우 여백 20을 줍니다. 배경이 있는 요소(검색창, 광고 배너)는 여백 20짜리 투명 Wrapper로 감쌉니다.

### 카드
- 방향 `Vertical`, 너비 `Fill container`, 높이 `Hug contents`
- 내부 여백 상하좌우 20, 정보 묶음(Info) 내부 간격 8, Info ↔ 버튼 16

### 텍스트와 버튼
- 제목: `textAutoResize = HEIGHT` + 최대 두 줄
- 버튼: `Fill container`
- 텍스트와 버튼이 겹치지 않아야 합니다.

## 8. Figma 편집 조건

- 텍스트, 필터, 카드, 버튼은 각각 직접 선택하고 편집할 수 있어야 합니다.
- 목록과 카드는 Auto Layout을 유지합니다.
- 화면 전체를 하나의 이미지로 만들지 않습니다.
- 아이콘은 벡터로 만들고, 브랜드 로고(카카오·네이버·Google)는 공식 에셋을 사용합니다.
- 기존 모임 정보와 정보 순서는 임의로 삭제하거나 변경하지 않습니다.
